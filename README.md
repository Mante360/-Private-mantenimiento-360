# MANTENIMIENTO 360° — Servicios Integrales

Prototipo web navegable de la plataforma Mantenimiento 360°.

## Qué incluye
- Pantalla inicial / identidad 360°
- Inicio con especialidades
- Solicitud de servicio
- Carga de fotos
- Localidad sin exponer inicialmente la dirección exacta
- Listado de profesionales
- Verificación de profesionales
- Mensajería de demostración
- Perfil de cliente
- Confirmación de pago
- Panel administrativo de demostración
- Diseño responsive para PC y celular

## Cómo probarlo
Abrí `index.html` en un navegador.

## Publicarlo en GitHub
Subí los archivos `index.html`, `styles.css`, `app.js`, `README.md` y `render.yaml` al repositorio.

## Publicarlo en Render
Crear un **Static Site** conectado al repositorio.
- Build Command: dejar vacío
- Publish Directory: `.`
- No se necesita servidor para esta primera versión.
